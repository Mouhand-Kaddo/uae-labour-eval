# The agent ends with a structured `final_answer` tool call

The agent must finish by calling `final_answer` with answer text, cited articles (instrument and article number), a status (`answered`, `refused`, `not_found`) and a refusal reason. Scoring citations, refusals and "not found" from free prose would mean parsing "Art. 51" and "المادة (51)" out of two languages and many phrasings, which makes scorer errors indistinguishable from agent errors. A cited article that does not appear in a chunk the agent retrieved during that case is an automatic fail, which catches made-up citations deterministically. The agent loop does not accept such an answer: it returns the `final_answer` call as a tool error naming the unread articles, so the agent reads them or drops them and calls again, within `max_turns`. The scorer still fails an answer that slips through (for example one that runs out of turns). Each sent-back answer is a `tool_call` step with an `unread` list, and `summary.json` counts them per case as `sent_back`, so the rate of made-up citations stays visible. Citations are scored at article level, not clause level.
